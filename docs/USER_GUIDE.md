# Anas 远程桌面 / Remote Desktop

## 简体中文

截图默认仅返回图片；传入 `save: true` 可同时保存到宿主数据目录下的 `tmp/anas-plugin-rdp/screenshots/`，成功返回绝对路径 `saved_path`，失败返回 `save_error` 并保留图片。临时文件不进入备份，可随宿主清理删除；此功能需要提供 `tempDirectory` 的宿主。

需要 **Anas 4.0.4 或更新版本**（插件 API 2），提供本插件使用的标题栏菜单、窗口状态、准备阶段适配、目录选择与文件定位接口。请先升级宿主，再安装插件。

桌面显示远程光标，模型操作时也可观察位置变化。模型移动仅在本地平滑显示，不增加远端鼠标事件，不延迟工具或改变截图；服务器编辑页可勾选「禁用鼠标动画」，默认不勾选。手动移动即时跟随，移出后保留最后位置，不发送归位或隐藏操作；锁定本地输入仍显示远程更新。光标随桌面缩放并跟随远端形状，位置未知或远端要求隐藏时不显示。

插件提供五个工具：`list` 查询服务器及运行状态，`profile` 管理保存的配置，`control` 控制运行状态，`screenshot` 截图，`input` 输入。操作统一使用稳定的 `profile_id`；`session_id` 仅标识当前连接。配置输入和输出使用 snake_case 字段。`profile.action` 为 `get/add/update/delete`；新增提供 `changes.host`，修改和删除要求最新 revision，修改只合并指定字段；连接运行、桌面打开或正在编辑时禁止修改和删除。`control` 的可选字段为 `state`、`location`、`ui_locked`、`reset_input`，省略表示不变。`foreground` 连接并显示桌面（不表示系统焦点），`background` 连接但关闭桌面，`closed` 断开并关闭桌面；`location: sidebar|window` 只与 foreground 使用，不修改保存的偏好。锁定／解锁用 `ui_locked: true/false`，重置用 `reset_input: true`；单独调用要求已连接，不隐式连接。closed 不能与其他操作组合。组合按连接、输入锁、键盘重置、展示的顺序执行；检查返回的 `ok`、实际状态和 `applied`，失败时依据 `failed_step/error` 处理，已完成操作不回滚。同一配置复用连接和页面，断开的桌面可原位重连；操作绑定选定连接，不把剩余输入转给新连接。`list` 包含当前配置、revision、连接和桌面状态，保留已断开的残留页面及外部删除配置后的资源。没有桌面时 `view` 为 null。

连接使用已保存密码和既有证书信任，缺少密码或证书待确认时需在界面处理。截图直接返回 PNG，使用原桌面像素坐标，默认在位置已知时包含光标。服务器修改工具只更新指定字段并检查 revision，保留其余配置和已保存密码；正在编辑、打开或连接时拒绝冲突操作。密码及证书仍在插件界面管理。`input` 支持 Unicode 文本 `text`、鼠标、按键名 `press`、组合键 `hotkey` 和原始扫描码；重复按键直接重复动作。键名统一使用无分隔符的大写写法，例如 `A`、`CTRL`、`ENTER`、`PAGEDOWN`、`PAGEUP`；无效输入在发送前报错并给出原因。使用截图原始像素坐标，每次最多 64 个动作。底层 down/up 独立发送，允许跨调用保持；插件不记录、保护或自动恢复工具按键状态。`press/hotkey` 始终发送自身的 up，也会松开此前已保持的同键；操作协调由调用方负责。顶层 `interval_ms` 为动作完成到下一动作开始的间隔，默认 50 ms，可设 0～1000 ms；按键／组合键内部固定保持 50 ms，整次输入执行期限为 300 秒；超过 10 秒可转为后台等待，继续等待同一调用，不重复发送。同一连接已有输入序列执行时，新输入返回忙碌；已派发序列在调用取消后仍完成指定动作，达到原执行期限、发送失败或断开则中止剩余步骤并报错，不追加松键或回滚。工具输入本身不改变本地输入锁；未锁定时用户可继续输入，后续工具调用始终可用。文本动作格式为 `{"type":"text","text":"你好，Anas 🐟"}`，整段算一个动作，内部每批最多 8 个 Unicode 字符、批后等待 50 ms，包含末批；interval_ms=0 也保留文本节流，不裁剪、转换换行或自动提交。每段最多 4096 个 Unicode 字符，整组 actions 的 JSON 序列化最多 12000 个 UTF-8 字节（含转义）。需要提交时在其后追加 `press ENTER` 或 `hotkey CTRL+ENTER`。目标应用对 Unicode 和控制字符的处理可能不同，接受操作后仍需截图确认结果。

随包 `remote-desktop` Skill 说明查询、截图、操作、再观察流程，选择其依赖工具后可使用。

1. 在 Anas「设置 → 插件」选择插件 ZIP，或完整解压目录中的 `PLUGIN.json`。
2. 从顶部插件菜单进入首页，默认在侧边栏显示服务器列表。在 Anas「设置 → 插件」选中 RDP 后，「首页打开位置」自动保存，下次打开生效；顶部入口遵循该设置。点击顶部「＋」新建服务器配置，填写名称、地址、端口、用户名和可选域，在「远程桌面打开位置」选择「侧边栏」或「独立窗口」。保存后返回列表，取消丢弃修改；单击条目选中，双击启动服务器；悬停或键盘聚焦一行也可「启动」「编辑」，不可编辑时隐藏「编辑」按钮。顶部「−」确认删除选中项，「↑／↓」移动选中项并自动保存顺序；右键条目可选择「侧边栏启动」「独立窗口启动」（运行中则为对应位置恢复桌面），以及编辑、复制、上移、下移或删除；编辑页仅保留保存和取消。
3. 如需记住密码，勾选「保存密码」并输入；留空且显示「已保存」时保留原密码。取消勾选后保存即删除密文。未保存的密码在连接页输入；该页也可勾选「保存密码（加密，可随备份恢复）」，点击连接时保存到原条目。不勾选则仅用于本次连接，不删除已有密码；条目已删除或保存失败会提示错误，不会重建条目。
4. 双击条目或点击「启动」，按服务器配置打开连接页；已保存密码时直接连接，否则输入密码后点击「连接」。普通打开首页、刷新页面或恢复备份均不自动登录。同一配置重复打开会聚焦已有页面。编辑和连接使用独立界面：保存只修改配置，连接和重新连接读取最新配置，不隐式保存。连接页与编辑页互斥：即使已断开，连接页仍在时也不能编辑；先关闭连接页并断开后台连接，再编辑。编辑期间须先保存或取消，才能打开连接页。指定位置打开或移动桌面仅影响当前页面，不自动修改「远程桌面打开位置」。该配置通过显式编辑保存修改；下次启动及后台桌面恢复时，未指定位置则使用配置值。连接页的密码默认仅用于本次连接，只有勾选保存时写入；异常断开后显示重新连接入口，不返回编辑表单。待连接表单居中显示，窄窗口和大字号下可滚动；连接后恢复完整桌面区域。
   使用 Anas 标签右键菜单或窗口标题栏切换位置，保留连接和未保存输入。关闭侧边栏桌面标签或独立窗口始终保留后台连接，没有单独的后台运行选项。恢复桌面接入同一连接。手动「断开连接」（包括服务器条目右键菜单）与工具 `closed` 均结束连接并关闭桌面；仅异常断开保留桌面和重连入口。连接独立于对话周期。列表仅在有连接或桌面时显示状态；无连接且无桌面时隐藏状态。停止插件或退出宿主结束连接。
5. 证书不受系统信任时，独立核对服务器证书 SHA-256 后再信任并重试。指纹变化会再次提示。
6. 在桌面区域操作键鼠；侧边栏连接页与独立窗口标题栏均提供断开／取消图标按钮，悬停可查看提示。从 Anas 顶部插件菜单可重新打开服务器列表，不影响当前连接。

密码采用内置版本密钥和随机 IV 的 AES-GCM 加密，仅避免明文直读；持有配置和插件代码即可解密。无需主密码或系统凭据库，可通过 Anas 数据备份跨机器恢复；备份应视为包含登录凭据。密码不回填表单，连接成功后清空临时输入。卸载默认保留配置，同 ID 重装后可继续使用；若勾选宿主卸载确认框的「删除插件数据」，服务器配置、保存的密码和首页偏好均删除，已有备份仍保留；旧版单服务器配置自动迁入。

最多保存 200 个配置，同时最多 4 条连接。启动及进入编辑会读取最新配置。配置在编辑期间被外部修改时，会拒绝覆盖并保留当前草稿；点击冲突提示旁的「重新加载」可读取最新配置，并放弃未保存的修改。运行中的配置禁止编辑、删除，断开后才可删除；编辑还需要关闭对应连接页。外部删除的配置如仍有后台连接，列表保留恢复与断开入口，但不能用已删除配置重连。损坏文件保留并报错，不自动重置。

已保存的首页位置选择继续保留。首页位置与每台服务器的远程桌面位置互不影响。修改首页位置不会关闭已有页面或迁移连接；保存失败会提示并恢复原选项。首页偏好保存在插件配置中，随 Anas 备份恢复，卸载默认保留。

名称与界面使用 Anas 同样的 i18next JSON 语言包，内置简体中文和英文。用户在 ZIP 的 `lang/` 内复制 `en.json` 为新语种（如 `fr.json`），修改 `_meta.name`、翻译文本并保留键和占位符，重新压缩完整插件后安装；插件只跟随宿主当前语种；宿主没有的语种不显示、不能选择。使用新语种前，须先向 Anas 数据目录的 `lang/` 添加对应宿主语言包，再重新打开 Anas。缺失文字回退英文。也可修改包内现有语种。卸载重装以新包为准，不保留或合并旧翻译，请保存修改后的 ZIP；详见随包 `lang/README.md`。语言、主题、字号在聚焦或约 5 秒内更新，保持连接。不同配置的连接独立；同一 Windows 账户重复登录可能导致服务端断开原会话。

每台服务器保留初始分辨率（默认 1280×800）及「窗口自适应分辨率」「侧边栏自适应分辨率」，两个开关默认关闭。连接并确认服务端支持动态分辨率后，两处工具栏显示分辨率菜单，包含常用尺寸和配置的自定义尺寸。底部「自适应」是独立复选项，对应当前位置，修改后立即保存到该服务器配置并生效；移动、重连及重启保留偏好。手动选择分辨率不改变自适应勾选或保存的初始尺寸；独立窗口恢复普通窗口并同时调整窗口和远端桌面，侧边栏只调整远端桌面。开启自适应时，独立窗口仅在用户调整边框、最大化或全屏后更新远端分辨率；移动、换屏和程序适配不改变它。侧栏在区域变化结束约 300ms 后自适应；取消自适应保持当前远端尺寸。隐藏或交接中的页面不调整，任何尺寸调整都不重新连接。服务端能力尚未就绪、不支持或动态调整失败时，独立窗口的同一按钮用于「适配桌面大小」，仅调整本地窗口；侧边栏隐藏分辨率菜单。失败会提示，保存的自适应偏好不清除。

侧边栏工具栏和独立窗口标题栏提供「输入文本」：可用本机输入法编辑多行内容，点击「输入到远程」或按 `Ctrl/⌘ + Enter` 发送，普通回车换行，不额外向远端发送回车。长文本按 Unicode 字符边界分批、等待回执并显示进度；发送中禁止重复提交和本地桌面输入。取消只停止未发出的部分，失败保留原文、已确认进度和剩余内容，提示可能部分输入，不自动重发。全部成功后才清空并关闭；页面交接保留草稿。

独立窗口显示前先恢复本次连接记住的普通窗口内容区域大小，没有记录时使用配置尺寸，再启用自适应。窗口尺寸、显示器和位置由插件后台会话保留，侧栏往返和关闭后恢复可复用；全屏、最大化、侧栏尺寸及侧栏修改的远端分辨率不覆盖记录，断开后清除。首次和恢复尺寸允许超过显示器；原显示器仍连接时恢复原位置，否则放回当前屏幕，拖出标签优先使用鼠标落点。独立窗口画面最多按一个远程像素对应一个界面逻辑像素显示，空间不足时等比缩小；窄侧栏中的远端应用可能无法完整布局。自定义宽高须为 200～8192 的整数，宽度须为偶数，总像素不能超过 16,777,216。

画面在可用空间内居中；独立窗口只缩小、不放大，侧边栏等比缩放。当前提供基本键鼠、证书信任和连接回收。声音、多显示器尚未提供。桌面直接键盘映射尚不支持本机输入法组合输入，可使用「输入文本」弹窗；远端输入法及复杂快捷键的效果依赖目标应用。

包内包含 canvas 界面、原生会话程序和第三方声明，无需 Rust 或 Node。通用 ZIP 自动选择 Windows x64、macOS Apple Silicon／Intel 程序；本机构建 ZIP 仅含本机平台。macOS 程序为 ad-hoc 签名，未经 Apple 公证。

独立连接窗口的标题栏显示连接状态和断开／取消图标，页面内不再重复显示连接栏；移回侧边栏恢复原布局，连接保持不变。

「重置输入」按钮与 `control({profile_id, reset_input: true})` 工具共用实现，发送 RDP Synchronize，锁定标志为 0：松开所有普通键和修饰键，同时关闭大小写、数字、滚动及 Kana 锁定，并在最后已知鼠标位置释放左、中、右键。它只在明确调用时执行，不随工具返回或对话结束触发；会中止该连接尚未发完的工具输入序列（原调用返回 `RDP_INPUT_RESET`），不改变连接或本地输入锁。侧边栏桌面工具栏和独立窗口标题栏均提供此按钮，锁定本地输入时仍可使用。

侧边栏桌面工具栏和独立窗口标题栏提供「锁定本地输入」。选中后屏蔽本地键盘、鼠标和滚轮，画面与模型工具继续工作；解锁、断开和关闭入口始终可用。模型可通过 `control({profile_id, ui_locked: true/false})` 设置，`control`、`list` 返回 `ui_locked`。锁属于当前连接，移动、后台恢复和对话结束均保留；新连接默认未锁定，不写入配置。模型完成连续操作后主动解锁，用户可随时手动解锁；它不限制其他工具调用者，手动解锁也不停止正在执行的工具。

每台服务器的「支持剪贴板」默认关闭；开启后，连接工具栏和独立窗口标题栏才显示剪贴板开关。每次新连接默认不共享，各连接可以独立开启，移动页面或保留后台连接不改变开关。只有活动桌面同步新内容：独立窗口须在前台；侧边栏须选中且正在操作其标签、画面或工具栏，点击聊天区、收起或切走标签后暂停。鼠标悬停不激活。失活连接保留已复制内容的粘贴能力，已有文件传输继续收尾；新活动连接接管新的同步，不关闭其他连接的开关。手动关闭共享仍须等文件传输结束；关闭不撤回已经复制的文本。按钮提示显示同步中、待激活或传输收尾。 剪贴板按独立通道状态启用：桌面已有画面但 CLIPRDR 尚未完成协商时，开关显示“剪贴板通道初始化中”并禁用；协议就绪后才允许手动开启，不自动开启共享。

Windows 支持文件和文件夹双向复制粘贴，复制时仅交换目录信息，粘贴时按需读取内容，不预下载远端文件、不移动或删除源文件。macOS Intel 已实测文本双向复制、本地文件夹上传、多连接活动切换及传输取消／断开。取消上传后，占用可能需约一分钟才释放。远端文件直接粘贴到 Finder 尚未实现；Windows 多连接切换及本机 Explorer 粘贴／取消仍待补验。图片和富文本暂不支持。

## English

Screenshots return images by default. With `save: true`, the same PNG is also saved under the host data directory at `tmp/anas-plugin-rdp/screenshots/`; metadata includes an absolute `saved_path` on success or `save_error` while retaining the image on failure. These temporary files are excluded from backups and may be removed by host cleanup. Saving requires a host that provides `tempDirectory`.

Requires **Anas 4.0.4 or later** (plugin API 2), which provides the titlebar menus, window state, fitting-before-activation, directory selection and file reveal APIs used by this plugin. Upgrade the host before installing the plugin.

The desktop displays the remote cursor, including movement from model tools. Model moves animate locally without adding remote input, delaying tools or changing screenshots. The server editor offers “Disable mouse animation”, unchecked by default. Local movement appears immediately; leaving the desktop retains the last position without sending a reset or hide operation. Locking local input still allows remote cursor updates. The cursor follows desktop scaling and server-provided shapes; unknown positions and server-hidden cursors are not drawn.

The plugin exposes five tools: `list` queries servers and runtime status, `profile` manages saved configuration, `control` changes runtime state, `screenshot` captures the desktop, and `input` sends input. All server operations use stable `profile_id`; `session_id` only identifies the current connection. Profile input and output fields use snake_case. `profile.action` is `get/add/update/delete`; add requires `changes.host`, update/delete require the latest revision, and update merges only supplied fields. Running connections, open desktops and active edits block profile changes and deletion. Optional `control` fields are `state`, `location`, `ui_locked` and `reset_input`; omitted fields stay unchanged. foreground connects and shows the desktop (not OS focus), background connects and closes its desktop, and closed disconnects and closes the desktop. `location: sidebar|window` requires foreground and never saves the preference. Use `ui_locked: true/false` to lock/unlock and `reset_input: true` for an explicit reset; without state these require an existing connection and never connect implicitly. closed cannot combine with other operations. Combined control runs connection, input lock, input reset, then presentation. Inspect `ok`, actual status and `applied`; failures include `failed_step/error`, and completed effects are not rolled back. The same profile reuses its connection and page; disconnected desktops can reconnect in place. Each operation stays bound to its selected connection and never redirects remaining input to a replacement. `list` includes configuration, revision, connection and desktop status, including disconnected pages and resources whose profile was removed externally. `view` is null when no desktop exists.

Connections use saved passwords and existing certificate trust; missing passwords or certificate confirmation require the plugin UI. Screenshots return PNG at original desktop coordinates and include the cursor when known. Profile updates change only the supplied fields at the current revision, preserving other settings and saved passwords. Editing, opening, and running sessions block conflicting changes. Passwords and certificates remain managed in the plugin UI. `input` supports Unicode `text`, mouse gestures, named-key `press`, `hotkey` chords, and raw scan codes. Repeat keys by listing the action again. Use uppercase key names without separators, such as `A`, `CTRL`, `ENTER`, `PAGEDOWN` and `PAGEUP`. Invalid input is rejected before dispatch with a validation reason. Coordinates use original screenshot pixels. Each call accepts up to 64 actions. Raw down/up events are independent and can span calls; the plugin does not track, protect, or restore tool-held keys. press/hotkey always send their own ups, including for previously held keys; callers coordinate their operations. Top-level `interval_ms` is the gap from one completed action to the next (0–1000 ms, default 50). Press/chord actions hold for 50 ms internally. The entire input call has a 300-second execution deadline. After 10 seconds it may continue in the background; wait for that call instead of resending it. Another input call on that session returns busy while a sequence is running. After dispatch, caller cancellation lets the sequence finish the requested events; the original execution deadline, send failure or disconnection stops remaining steps and reports an error without extra releases or rollback. Tool input does not change the local input lock; users can continue entering input when unlocked, and subsequent tool calls remain available. Use `{"type":"text","text":"你好，Anas 🐟"}` for text. The whole text is one action, paced in batches of at most 8 Unicode characters with 50 ms settling after each batch, including the last. Setting interval_ms=0 does not disable this pacing. There is no trimming, newline conversion or automatic submission. Each text accepts up to 4096 Unicode characters; the complete actions JSON is limited to 12000 UTF-8 bytes, including escaping. Follow it with `press ENTER` or `hotkey CTRL+ENTER` when intended. Unicode and control-character behavior depends on the target application; observe a new screenshot after input to confirm its effect.

The bundled `remote-desktop` Skill describes querying, observing, acting and observing again; enable its tool dependencies to use it.

   Use the sidebar toolbar’s Move to separate window icon, the Anas tab context menu or the window titlebar to move a desktop while retaining its connection and unsaved input. Passwords use AES-GCM with a built-in versioned key and random IV, only concealing plain text: anyone with the configuration and plugin code can decrypt them. No master password or OS vault is needed. Anas backups restore them across machines; treat backups as containing login credentials. Passwords are not filled back into forms; temporary input clears after connection. Uninstalling retains profiles by default for reinstallation under the same ID. Selecting Delete plugin data in the host’s uninstall confirmation also removes profiles, saved passwords and home preferences; existing backups are kept. Older single-server settings migrate automatically.

Up to 200 profiles and four concurrent connections are supported. Start and Edit read the latest profile. If a profile changes externally during editing, stale saves are rejected while preserving the draft. Select Reload beside the conflict message to load the latest profile and discard unsaved edits. Running connections block profile editing and deletion. After disconnecting, deletion is allowed; editing also requires closing the connection page. If a profile was removed externally, its running session remains listed with Resume desktop and Disconnect, but cannot reconnect after it ends. Damaged files are preserved and reported rather than reset.

Existing home location preferences are retained. The home page location and each server’s remote desktop location are independent. Changing the home location does not close existing pages or transfer connections. A failed save displays an error and restores the previous choice. The home preference belongs to plugin configuration, is included in Anas backups, and survives uninstalling unless the host’s Delete plugin data option is selected.

Names and UI use the same i18next JSON format as Anas, with English and Simplified Chinese included. In the ZIP’s `lang/`, copy `en.json` to a new code such as `fr.json`, change `_meta.name`, and translate values while retaining keys and placeholders. Repack the complete plugin and install it. The plugin follows the host’s selected language; plugin-only languages are not shown or selectable. To use a new language, first add its host language pack to `lang/` in the Anas data directory and reopen Anas. Missing text falls back to English. Existing languages can also be edited in the package. Reinstallation uses only the new package without retaining or merging old translations; keep your customized ZIP. Each profile has its own connection; Windows may disconnect an earlier session when the same account signs in again.

Each profile keeps an initial resolution (1280×800 by default) and independent “Adapt resolution in windows” and “Adapt resolution in sidebar” preferences, both off by default. After connection and confirmation of server support, both toolbars offer a resolution menu with common sizes and the configured custom size. Its bottom “Adaptive resolution” checkbox applies to the current location and immediately saves the preference to the profile; moves, reconnections and application restarts preserve it. Choosing a resolution changes neither this checkbox nor the saved initial size. In a separate window, selection restores a normal window and resizes both the window and remote desktop; in the sidebar, it changes only the remote desktop. With adaptation enabled, separate windows update the remote resolution only after a user resizes their border, maximizes or enters fullscreen; moving, changing displays and programmatic fitting do not change it. Sidebars adapt about 300ms after their area changes settle. Disabling adaptation retains the current remote size. Hidden or transferring pages do not resize, and resizing never reconnects. While support is unknown or unavailable, or after a dynamic resize failure, the same window button performs “Fit window to desktop” locally; the sidebar resolution menu is hidden. Failures are reported without clearing saved adaptive preferences.

The sidebar toolbar and separate-window titlebar provide “Input text”. Compose multiline text with the local IME, then click “Input to remote” or press `Ctrl/⌘ + Enter`; plain Enter inserts a newline, and sending does not append a remote Enter key. Long text is split at Unicode character boundaries and sent sequentially with acknowledgements and progress. Duplicate submission and local desktop input are blocked while sending. Cancel stops only unsent batches. Failure retains the original, confirmed progress and remaining text, warns that input may be partial, and never automatically replays it. Only complete success clears and closes the dialog; page handoff preserves the draft.

Before becoming visible, separate windows restore the normal content-area size remembered by the live plugin session, or use the configured size when none is recorded, before adaptation starts. Window size, display and position survive sidebar moves and closing/reopening a window; fullscreen, maximized and sidebar sizes or sidebar resolution changes never overwrite them. Disconnecting clears this memory. Initial and restored sizes may exceed the display. Windows return to the recorded display when available, otherwise the current screen; dragging out a tab takes precedence over the remembered position. Separate windows display at most one remote pixel per CSS pixel and scale down when needed. Remote applications may not fit very narrow sidebars. Custom dimensions must be integers from 200 to 8192, with even width and at most 16,777,216 pixels.

The desktop is centered in the available space: separate windows scale down only, while the sidebar scales proportionally. Basic keyboard/mouse input, certificate trust, and cleanup are provided. Audio and multiple displays are not provided. Direct desktop key mapping does not support local IME composition; use the “Input text” dialog; remote IME and complex-shortcut behavior depends on the target application.

Packages include canvas UI, native session helpers, and notices; no Rust or Node is needed. Universal ZIPs select Windows x64 or Apple Silicon/Intel macOS helpers automatically; local builds contain only the local platform. macOS helpers are ad-hoc signed and not notarized.

Connection windows show status and a Disconnect/Cancel icon in the host titlebar. Moving back to the sidebar restores the connection header without reconnecting.

The Reset input button and `control({profile_id, reset_input: true})` tool share one implementation: RDP Synchronize with toggle flags 0 releases ordinary keys and modifiers and turns off Caps Lock, Num Lock, Scroll Lock and Kana Lock, and releases the left, middle and right mouse buttons at the last known pointer position. It runs only on explicit invocation, never on tool or conversation completion. It interrupts any pending tool input sequence on that connection (the original call returns `RDP_INPUT_RESET`) without changing the connection or local input lock. The button is available in both the sidebar toolbar and separate window titlebar, including while local input is locked.

The desktop toolbar and separate window titlebar provide Lock local input. When selected, local keyboard, mouse and wheel input are blocked while display and model tools remain available; unlocking, disconnecting and closing remain available. Models use `control({profile_id, ui_locked: true/false})`; `control` and `list` return `ui_locked`. The lock belongs to the live connection and survives moves, background recovery and conversation completion. New connections start unlocked; it is not saved in configuration. Models explicitly unlock after continuous work, and users can unlock manually at any time. The lock does not exclude other tool callers, and manual unlocking does not stop an executing tool.

Clipboard support is off by default for each server; enabling it reveals the clipboard toggle. Each new connection starts with sharing off. Connections can enable sharing independently, and moving or retaining a desktop in the background preserves its switch. Only the active desktop synchronizes new content: a separate window must be foreground; a sidebar desktop must be selected and its tab, content or toolbar must be the current interaction region. Clicking the chat area, hiding the sidebar or switching tabs pauses synchronization; hovering does not activate it. Inactive connections retain published copies for pasting and finish existing file transfers. A newly active connection takes over new synchronization without disabling the other switches. Manually disabling sharing still waits for file transfers to finish and does not retract copied text. Tooltips indicate syncing, waiting for activation or finishing a transfer. Clipboard availability follows its own channel state. When the desktop is visible but CLIPRDR negotiation is incomplete, the disabled switch shows “Clipboard channel initializing”. Protocol readiness enables the switch; sharing still requires an explicit click.

Windows supports bidirectional file and folder copy/paste: copying exchanges metadata, and pasting reads file contents on demand. Remote files are not downloaded in advance, and source files are never moved or deleted. Intel macOS tests cover bidirectional text, local-folder uploads, active-connection switching, and transfer cancellation/disconnection. An upload may remain busy for about a minute after cancellation. Direct remote-file paste into Finder is not implemented; Windows multi-connection switching and local Explorer paste/cancel still need verification. Images and rich text are not supported.

### macOS 文件下载 / File downloads

macOS 开启共享后，远端复制文件／文件夹会显示下载图标；悬停可查看项目数量。点击选择本机保存目录，才开始分块下载。直接保存到所选目录，保留远端文件夹原有结构；若已有同名文件或文件夹则提示冲突，不覆盖、不合并；进度提示支持取消，完成后可在 Finder 中显示。切换标签、关闭桌面或侧栏／窗口交接不停止后台下载；明确断开连接或停止插件则结束下载并清理本次部分文件。清理失败会提示保留目录。需要提供目录选择和文件定位接口的新版 Anas；不支持跨应用重启恢复任务。

On macOS, sharing reveals a download icon when remote files or folders are copied; its tooltip shows the item count. File contents are read in chunks only after you click and choose a local destination. Downloads save directly into the selected directory, preserving the original remote folder structure. Existing files or folders with the same name cause a conflict error; they are never replaced or merged. The progress panel supports cancellation and Show in Finder on completion. Switching tabs, closing the desktop, or moving between sidebar and window keeps the download running in the background. Explicitly disconnecting or stopping the plugin ends the download and removes partial files; cleanup failures identify the retained folder. This requires an updated Anas with directory selection and file reveal APIs. Transfers do not resume after an application restart.
