# RDP 插件开发说明

## 边界与依赖

宿主提供普通窗口、隔离 iframe、稳定面板身份和异步交接；不理解 RDP。插件仅使用公开 `window.anas` 接口，最低要求 Anas 3.3.13（插件 API 2）。依赖标题栏 `items` 菜单及 `separatorBefore` 分组、`onViewChanged.activity/windowMode/windowPlacement/viewport` 通知、准备阶段 `resizeWindow` 与激活后显示窗口、包内图标、后台 `host.onViewsChanged` 活动订阅、`host.closeView` 指定实例关闭及 `tempDirectory` 临时目录。使用 API 2 页面交接与指定实例移动，无 API 1 兼容分支。

IronRDP 固定为 `2c08bda7c5f9ad490e01f123b3be5521cf3c6e9d`。`native/src/session.rs` 复用其 `RdpClient`；连接、认证、协议、解码及完整桌面画面均在原生进程。前端 `src/ui/desktop.ts` 仅绘制 canvas 并发送输入。页面重建与交接不停止 RDP 引擎；实际关闭桌面仅释放展示，连接保留在后台；不自动重连已结束的连接。

## 文本输入弹窗

侧栏和窗口工具栏共用 `TextInput`。原生多行文本框支持本机输入法；仅点击发送或 `Ctrl/⌘ + Enter` 提交。每批最多 128 个 Unicode 字符，按序列化后的请求字节数再次约束；`inputText` 校验连接、页面租约和本地输入锁，通过现有原生 `input/text` 节奏输入，收到回执才增加确认位置。普通回车是文本换行，不附加 Enter 按键。

同一发送任务固定连接和页面；连接替换、锁定或页面交接时不把剩余内容转给新连接。发送中屏蔽本页键鼠，取消和交接等待当前短批回执，再停止未发部分；失败批可能已部分送达，保留原文、确认位置及剩余内容，要求检查后明确编辑剩余内容，不自动重放。页面快照保存草稿，全部成功才清空；不新增模型工具、配置或对话控制权。

## 会话与交接

后台按服务器配置 UUID 管理资源，最多四条连接；展示页另有唯一 pageId。`create` 通过私有 stdin 交给 helper 凭据；`find` 接入已有资源；`runtime.state` 返回不含凭据的会话摘要、连接页和编辑状态；打开位置直接读取服务器配置，不单独维护后台偏好；配置被外部删除时才使用会话快照中的恢复位置。`lease/claim/release` 管理输入归属；`disconnect` 明确终止资源。RPC 只用于短控制操作。

展示流使用 loopback `/display` WebSocket，限定包 origin，随机票据采用常量时间比较。新页先获取完整画面、光标及状态，绘制并确认后才可接管输入。输入租约同时比较原 owner 和递增 epoch，拒绝陈旧页面及过期交接。页面切换、失焦和展示连接断开仅对本地 UI 记录的按键发送松开事件；不记录或清理工具按键。页面释放时若队列暂满，保留本地 UI 松开事件并在同一连接内重试，不断开 RDP；后续工具输入和页面接管先提交这些遗留松开事件，迟到重试不能释放新页面或工具后来按住的键。

`prepare` 冻结输入，等待保存、连接等操作完成，返回草稿、滚动位置、会话引用和租约。目标从 `getContext()` 主动读取恢复信息，附着原连接，等待首帧后 `ready()`；`activate` 原子接管输入。成功后旧页 `dispose` 只释放画布和订阅；失败先移除目标，再由原页 `resume` 重新取得租约。异步生命周期检查取消信号。恢复以交接快照为准，不依赖原服务器配置仍存在。回退时，仍在进行的连接操作负责自己的最终接管；已结束会话释放展示并恢复断开状态的控件。显示流单独丢失时重新附着原会话，不新建或终止 RDP 连接。

后台保留最新完整 RGBA 帧；每个展示连接最多一帧待确认、最多约 30 fps，慢页跳过中间帧。图像限制为 16M 像素，读写有超时；输入拥塞不静默丢弃按键。当前完整帧传输尚未做差分压缩，高分辨率／高刷新负载需要实测。后台在没有页面时继续处理协议和画面。

光标单独叠加在页面画面上，按桌面缩放、热点和边界裁切；默认箭头与工具截图复用原生位图。展示快照携带已知坐标，形状仅变化时发送，桌面图像仅帧版本变化时发送；位置变化沿用约 30 Hz、单条待确认及合并更新机制，不重传整张桌面。手动移动沿用原输入通道并立即更新本地图层；页面鼠标序号随已接受输入回传，迟到位置不覆盖尚未确认的新移动。移出后保留最后位置，锁定本地输入仍显示工具／远端更新；未知位置或远端隐藏时不画光标。新页面接入获取当前图像、形状与位置，不依赖旧页面。纯工具移动携带显示提示，前端以约 80–160 ms 动画插值；新目标替换当前动画，点击／滚轮及本地输入立即对齐。插值不发送输入、不延迟回执或改变截图；未知／隐藏位置及页面销毁取消动画，首次显示直接定位，并尊重系统减少动态效果偏好。

右键两种位置入口可启动、恢复或移动同一桌面。指定位置及页面交接只改变当前展示，不写入 `open_mode`、不增加配置 revision；该字段仅由显式配置保存修改。已打开页面沿用实际位置，新页面未指定位置时取配置偏好，后台桌面恢复也遵循此规则。

关闭侧边栏桌面标签或独立窗口始终保留后台连接，没有单独的后台运行选项。恢复桌面接入同一连接。手动「断开连接」（包括服务器条目右键菜单）与工具 `closed` 均结束连接并关闭桌面；仅异常断开保留桌面和重连入口。连接独立于对话周期。`dispose(closed)` 调用 `connection.close` 仅取消尚未消费的启动意图并释放展示，迟到的创建结果保留。主动断开通过 `server.close` 与工具状态切换共用按配置串行的后台操作，停止连接后通过宿主 `closeView` 关闭页面；关闭失败保留可重试页面。首页每秒及聚焦时刷新状态；已断开页面检查新的启动意图或工具创建的替代连接，重新接入同一实例。停止后台、停用、卸载、备份恢复及退出宿主沿用资源停止边界。明确停止后台时先阻止新建连接并关闭已存在的 helper，再等待资源操作和在途输入回执结束，避免启动或长输入阻塞清理入口。后台异常退出关闭 stdin，helper 自行结束；页面不承担资源保活责任。

页面复合操作使用宿主通用 `backend.call(method, params, { concurrent: true })`，允许关闭或移动页面时的生命周期回调进入后台；业务顺序由上述配置队列维护，等待页面操作时不持有资源锁。宿主只负责通用 RPC 调度和页面生命周期，不识别 RDP 配置或连接。

## 界面职责

首页列表单击选中、双击启动；条目右键菜单提供启动、编辑、复制、排序和删除，与现有按钮复用业务操作。菜单支持键盘导航、边界避让，页面交接时关闭。编辑页只有保存和取消。连接页与编辑页互斥：连接页存在（即使断开）或后台会话运行时不能编辑；编辑期间不能打开连接页。列表编辑按钮仅在可编辑时显示。后台运行时不能删除。宿主在每次后台调用中提供当前插件面板和调用者的稳定身份，插件按此维护编辑锁及短期打开预留；移动保留锁，保存／取消／关闭释放，异常关闭由下一次宿主快照回收。界面可用性与后台校验共同覆盖延迟刷新和并发操作。配置编辑使用独立表单，表单仅由保存／复制／删除等显式操作写入；打开及移动桌面不写配置；连接页默认使用临时密码，勾选保存后通过 `profiles.savePassword` 仅更新原条目的加密密码，保留其余配置并检查 revision。条目已删除、冲突或写入失败时保留输入并报错，不启动连接、不重建条目。新建连接通过 `profiles.get` 读取最新配置，已建立会话使用自身快照；关闭连接页并停止会话后才允许编辑，下次连接读取保存结果。页面交接分别保存编辑草稿、连接页密码及保存选项，交接本身不写入密码。仅待连接表单使用居中卡片；列表铺开、编辑页限制表单宽度，不套外框。连接后画布使用剩余空间。

工具栏图标均放在插件 `assets/`；`connectionActions` 提供包内相对路径，侧栏与宿主标题栏通过图片原样显示同一 SVG；断开图标自带红色，普通图标在 SVG 内适配明暗主题，禁用状态由按钮灰显，不维护宿主内置图标名映射。侧栏移出与窗口移回按钮成对、均位于断开右侧；两处连接状态使用同一语义色，明暗色值与宿主一致。

## 证书与配置

TLS 先执行系统信任及名称验证；不可信证书需用户核对 SHA-256 后按主机、端口固定叶证书。已有指纹变化时拒绝，即使新证书已被系统信任也不能绕过。`native/vendor/ironrdp-tls` 是固定提交的最小补丁：验证成功也调用证书回调，TLS 签名校验仍由原实现完成。来源及修改见该目录 `ANAS_CHANGES.md`，补丁有行为测试。

配置集中在 `plugins_data/rdp/profiles.json`，显式格式 v0，200 项、1 MiB 上限，revision 防止覆盖并发编辑。保留既有单配置迁移及密码解密能力。密码使用内置版本密钥 AES-GCM，只避免明文直读；持有配置和代码即可解密。临时凭据不写入日志、命令行或明文文件。用户说明须保留这一限制。

首页位置来自宿主通用 `home_open_location`，每台服务器另有打开位置。语言、主题和字号跟随宿主；独立窗口标题栏状态／操作图标由通用工具栏接口提供。清单默认图标为 `assets/remote-desktop.svg`；连接页通过 `openView.icon` 使用 `assets/desktop.svg`，宿主在菜单、标签及窗口标题栏显示。

服务器的 `disable_mouse_animation` 为 v0 可选布尔字段，缺失默认 `false`，UI 名称为「禁用鼠标动画」（默认不勾选），TS 使用 `disableMouseAnimation`。保存、复制、工具局部更新与会话／页面交接保留该选择，只供前端显示层使用，不传入 RDP 连接参数。

服务器固定分辨率 `desktop_width`／`desktop_height`（默认 1280／800）及自适应开关 `adaptive_window`／`adaptive_sidebar`（默认 false）均为 v0 可选字段。TS 使用 camelCase；正常读取补默认值，不升级格式。配置读写、复制、工具局部更新与两种连接入口保留这些值；页面交接保留编辑草稿及会话快照。固定值用于连接初始分辨率及无窗口记忆时的本地窗口尺寸，不作为自适应下限。未启用当前位置自适应时，不自动发送远端尺寸调整。

`AdaptiveResolution` 使用宿主分配的浮点 CSS 视口，扣除插件自己的控件区域。侧栏观察区域变化；独立窗口仅在宿主 `windowResizeRevision` 更新或用户开启自适应时处理新的尺寸操作，300ms 合并调整。移动、DPI 取整和程序调整窗口不派发远端调整；DPI 过渡中取消待派发的自动调整，恢复原尺寸不重复发送，派发前及异步上下文读取后再次校验布局。尺寸限制为 200～8192、偶数宽度和 16M 像素；不乘设备像素比。派发前检查活动生命周期、可见性及展示租约，交接取消延迟任务并等待在途短请求；旧页及旧 epoch 在 helper 再次拒绝。本地键鼠按下或工具长输入未完成时延后调整。未勾选侧边栏自适应时，移回、隐藏后恢复及调整侧栏宽度均保留远端尺寸；仅缩放展示。未启用窗口自适应时，移入独立窗口只恢复本地窗口尺寸，保留远端分辨率；画布和鼠标按服务器实际帧尺寸工作。服务端拒绝状态保存在原生会话快照，页面重建后仍可见。

动态分辨率能力通过 IronRDP 的 `ConfigBuilder.with_dvc` 注册 `DisplayControlClient`，由真实服务端 capabilities 回调更新原生 `resizeSupported` 快照；不发送试探 resize、不改上游依赖。每个新页面主动收到完整能力快照，菜单依据能力及调整错误状态显示，不依赖自适应开关。

两处菜单包含常用尺寸、配置尺寸及底部带分割线的「自适应」checkbox。`setAdaptive` 仅允许当前连接页和输入租约按位置修改该布尔项，写入与连接资源操作串行；配置存储在自身队列中读取最新数据并局部合并，递增 revision，保留密码和其他字段。保存成功后更新后台会话投影及页面；失败保留原勾选并提示。完整配置编辑仍与连接页互斥。交接等待保存结束，新页面从后台 `status` 获取最新两个偏好，避免旧交接快照覆盖保存结果。

手动选择不修改配置或自适应状态。窗口内先恢复普通窗口并调整桌面区域，再明确发送远端 resize；侧栏只发送远端 resize，不改变本地窗口记忆。手动请求取消尚未派发的自动调整，窗口中保持到下一次用户调整边框、最大化或全屏；侧栏中保持到区域再次变化。取消自适应不恢复旧尺寸。输入忙碌等临时拒绝显示可重试提示，不禁用动态能力；重试成功清除提示。

`native/vendor/ironrdp-client` 保留固定上游源码及许可证，增加可禁用的 Resize 重连策略，详见其 `ANAS_CHANGES.md`。首次通道协商单独等待最多 30 秒，已建立通道的调整响应等待 3 秒；更新等待目标不延长期限。展示通道不可用或等待超时，保留仍活动的连接并停止调整；重激活过程本身失败则终止并报错，不重连。

独立窗口通过 `anas.resizeWindow` 恢复本次后台 Session 的普通窗口插件内容区域 CSS 尺寸、显示器 ID 和工作区内 DIP 位置；无记录使用配置分辨率，不沿用侧栏当前帧。目标页面在隐藏窗口的 `activate` 阶段恢复尺寸；首次连接尚无画面时按配置设置将来的桌面区域。宿主等待激活完成后才显示窗口，随后启动自适应，后续帧不反向改变窗口。程序适配时记忆请求的逻辑内容尺寸；用户调整窗口后才以宿主 `viewport` 更新尺寸，移动只更新位置。原生取整不得反向污染窗口记忆，不取远端帧或 iframe 内部暂态尺寸；宿主位置／视口通知触发普通窗口状态确认后按变化合并保存（300ms），画面刷新不推迟保存，移动／关闭前等待最后一次保存；后台按会话与输入租约校验，拒绝旧页面写入。关闭页面、侧栏往返保留记录，断开清除；不写配置、不跨连接或应用重启持久化。宿主仅通过 `getContext()`／`onViewChanged` 报告 `windowMode/windowPlacement/windowResizeRevision/viewport`，不保存插件窗口状态；最大化和全屏不覆盖普通窗口记录。初始调整失败时提示并暂停自适应及记录，避免默认窗口污染记录。

独立窗口中，能力尚未就绪、不支持或调整失败时，同一位置提供「适配桌面大小」，按实际帧调整本地窗口并传 `restore: true`；侧栏此时不显示分辨率菜单。支持时，无论自适应是否开启，都提供菜单。恢复位置使用 `resizeWindow.restorePlacement`，原显示器断开时保持尺寸并使标题栏可触达，拖出指定的位置优先。宿主仅处理通用菜单、分组、标题栏、窗口尺寸和显示器定位，不理解 RDP 配置与协议。

## 模型工具

截图的可选 `save` 使用后台激活上下文的 `tempDirectory`，不接受任意输出路径、不从插件数据目录推导宿主路径。保存原生返回的同一 PNG，以唯一文件名暂存后原子发布，成功后才返回 `saved_path`；写入失败保留图片并返回 `save_error`，取消清理未完成文件。每次写入重建目录，兼容运行期间的手动清理。临时文件不备份，不保证长期存在；宿主未提供接口时明确报告保存失败。截图工具含可选写入，恢复策略声明为 `confirm`，只影响丢失回执后的重试，不增加正常调用审批。展示用 Markdown 的建议仅保留在 Skill。

`tools.json` 静态声明服务器状态、配置管理、截图和输入工具，构建时写入清单；后台工具直接复用配置和连接，不创建第二套状态或连接服务。

截图冻结原生进程当前完整帧、光标和已知位置，后台线程编码 PNG；每会话同时最多一次编码，最大 25 MiB，首帧未到明确报错。返回标准文本／Base64 图片块，文本包含原桌面尺寸、捕获时间及帧／光标／输入版本和时间。光标处理隐藏、默认箭头、热点、透明度与边缘裁切，位置未知返回 `null`；这些时间记录本地收到或接受事件的时刻，不表示远端原子同步或动作已完成。截图和查询不取得输入控制权。关闭页面后，后台运行中的连接仍可截图；已终止的连接不提供历史画面。

`control` 使用 `profile_id` 指定服务器，`state` 为 `foreground`（连接并显示桌面）、`background`（连接但关闭桌面）或 `closed`（停止连接并关闭桌面）。前台可选 `location: sidebar|window`，不改变保存的打开位置。同一配置复用连接和页面；已有桌面断开时，再次启动会重连并复用该页面。`list` 同时返回配置、连接状态、`session_id` 和实际 `view`，没有桌面时 `view` 为 `null`；已断开的残留窗口也可查询和关闭。截图、输入、重置输入和本地输入锁也统一使用稳定的 `profile_id`；`session_id` 仅供观察当前连接。工具开始时绑定当时的连接，断开后不会把剩余输入发送到重连后的新连接；未连接时明确报错，不自动连接。同一配置的工具状态操作、UI 启动／断开和连接创建共用顺序队列；主动断开会取消此前尚未完成的打开／认证，普通关页不触发取消；创建时复用已有连接，并拒绝来自已销毁页面的迟到请求。页面关闭回调只释放展示，不等待正在等自身关闭的业务操作。关闭失败保留原连接身份与错误，轮询只接入不同的新连接，不悄悄恢复原连接。连接读取最新保存的配置、密码和证书信任；缺少密码返回 `ok: false` 和 `RDP_PASSWORD_REQUIRED`，连接状态仍报告实际值，证书或连接失败返回实际状态。取消或超时仅清理本次新建且尚未连上的尝试，不影响复用或已建立的连接。getViews 用于报告真实页面及校验编辑冲突，不承担连接保活。

服务器工具 `profile`（`action: get/add/update/delete`） 复用 `Profiles` 和后台业务锁；更新只合并声明字段，写入前检查最新面板、编辑锁、启动预留、运行状态与 revision。取消在排队和原子替换前生效，已提交写入返回真实结果；`profile` 和 `control` 统一标为 `confirm`（宿主当前按工具声明恢复策略，含查询／锁定分支），仅不确定效果的恢复重试需确认，不能把 revision 当作丢失回执后的幂等保证。密码及证书沿用界面流程，查询不输出密码。

`control` 同时支持可选 `ui_locked` 和 `reset_input: true`；state 省略时只操作派发时绑定的既有连接。Schema 与后台均拒绝空请求、无关字段和矛盾组合，closed 不接受其他字段。顺序为连接、锁定／解锁、重置、更新展示，仍使用同一服务器队列。返回 `ok`、实际状态、`applied` 回执及失败时的 `failed_step/error`；状态查询本身失败则明确返回 `status_error`，不伪造状态。派发前的参数／取消错误直接拒绝，已开始的步骤保留真实结果，不回滚或重放。工具配置、view 字段统一 snake_case，页面内部类型保持不变。

旧工具入口不保留别名；模型 Skill 依赖更新为 list/control/screenshot/input。使用自定义工具细选的项目或子 Agent 需重新选择新入口，不把旧查询权限自动扩大为配置写入权限。

## 构建

Node 24、Rust 1.94.1；在 `native/` 运行 Cargo 以使用固定工具链。无需 WASM 工具链。`npm run build` 生成本平台 `dist/`，包括 UI、Node 后台、`anas-rdp-session`、双语说明及许可证；最终用户不需要 Rust 或 Node。

`npm run prepare:upstream` 仅供核对固定源码与声明，正常构建由 Cargo 获取锁定依赖。日常不生成 ZIP；发布时打包、核对条目及摘要，macOS 核对可执行权限及 ad-hoc 签名。CI 规则见[发布流程](SOURCE_PUBLISHING.md)，实际验证范围见[测试说明](TESTING.md)。

## 工具输入与页面交接

`input` 对 1～64 个动作整批校验，坐标必须位于当前桌面范围。`press` 按键名完成一次按下／松开，`hotkey` 按数组顺序按下组合键、反序松开；重复按键直接重复动作。两者内部保持 50 ms，对外名称统一为无分隔符的大写写法，例如 `A`、`CTRL`、`PAGEDOWN`、`PAGEUP`，与页面输入共用 `src/key-codes.json` 的扫描码表。内部仅对键名去除 ASCII `_`、`-` 并忽略大小写，再匹配已有键名和简写；不逐个添加分隔符别名，不处理文本内容。空名称、未知键名仍拒绝；组合键解析后检查重复。无效键名在派发前拒绝整批动作，`RDP_INVALID_INPUT` 携带具体校验原因。保留 Set 1 扫描码 `key` 及鼠标动作。`text` 按 Unicode 字符编码为 UTF-16，逐字符发送 Unicode down/up，补充平面字符先按高／低代理项发送 down，再按相同顺序发送 up；复用 IronRDP 原生事件及协议分包，不维护 Unicode 持键状态。每个文本动作 1～4096 个 Unicode 字符，完整 actions 的 JSON 序列化最多 12000 个 UTF-8 字节（包括转义），后台和原生层均校验；拒绝不完整的代理项，不替换或截断文本。

顶层 `interval_ms` 仅控制上一动作完成到下一动作开始的间隔，默认 50 ms，范围 0～1000 ms；0 取消动作间停顿，仍保留按键内部保持时间。整段 `text` 算一个动作，内部按最多 8 个 Unicode 字符分批，每批后等待 50 ms（包括最后一批）；完整代理项及对应 down/up 不拆到不同批次，末批等待完成才结束该动作，避免连续调用或 interval_ms=0 绕过节流，文本之后的按键／组合键按数组顺序执行；文本不裁剪、不转换换行、不追加回车或松开修饰键，不通过剪贴板或扫描码回退。Unicode 控制字符由目标应用解释，明确按键操作仍用 `press/hotkey`。保留动作数量和字节预算，先验证完整手势再派发，不再限制计划等待合计为 4 秒。原生事件循环通过定时分步入队，等待期间继续处理协议、截图、页面交接和断开；只在实际入队时持有输入锁，不因迟到的定时器连续补发。鼠标位置仅随本步鼠标事件更新，键盘步骤不回写旧位置。无等待的原始动作仍一次入队。

工具输入严格发送明确请求的事件：底层 `key/button down/up` 不补齐，`press/hotkey` 始终发送约定的 down/up，即使同键此前已经按住。插件不保存工具持键集合，不区分按键归属，也不在开始、结束、失败或页面交接时插入工具松键。跨调用保持由远端实际输入状态自然延续，模型决定何时发送 up；后续组合键及人工操作同样可能改变该状态。截图仅观察，不改变输入。

每条连接同时最多执行一条工具输入序列，重叠调用在派发前返回 `RDP_INPUT_BUSY`；已经发送的 down 不占用执行槽。不登记模型或对话身份，也不占用页面输入权。派发前取消不产生输入，派发后取消仍等待已接受的有界序列完成指定事件；入队失败或断开中止剩余步骤并报错，不回滚已发送事件、不追加松键，不因持键主动断开。返回 `accepted` 表示所有步骤已入原生队列，不证明远端应用完成；回执丢失不盲目重放。

输入工具声明 300 秒执行期限，后台把同一绝对 deadline 传给 Rust，再转换为单调时钟预算；不为每批重新计时，也不另设 5 秒回执超时。现有数量／字节上限下，计划等待的保守上界小于 145 秒，剩余预算用于调度与处理延迟。已知剩余时间不足以执行完整序列时在发送前拒绝；执行期间到期则停止未发送步骤并回报 RDP_INPUT_TIMEOUT，可能已部分执行，不松键、不终止连接。长序列超过 10 秒沿用宿主后台调用及 wait_call。调用方取消仍不改变已接受序列的原执行期限；截图、页面交接及对话结束不清除输入。宿主单次调用取消或超时只通知对应处理器并保留在途槽位、RPC 顺序及真实迟到回执，不终止共享后台。插件／宿主明确停止或进程实际退出时才沿生命周期边界回收连接。

页面 owner／epoch 仅用于侧栏和独立窗口交接时拒绝旧页面事件，与对话无关。工具与未锁定的页面输入仍可交错，连续操作需显式使用本地输入锁；完成后页面可直接继续操作，后续工具调用同样可用。

`control` 复用后台 `host.openView/moveView/closeView`。等待页面准备、移动或关闭时不持有 RDP 资源锁，允许生命周期回调进入后台。关闭接口按 instanceId 定位，窗口已断开或配置已删除时仍可清理。`list` 额外保留未匹配保存配置的连接／窗口，避免遗留资源不可见。Skill 使用标准元数据，工具依赖在构建清单中声明。

## 明确重置输入

工具 `control(reset_input=true)`、侧栏按钮和窗口工具栏均通过后台 `resetInput` 调用同一原生操作。使用 IronRDP `FastPathInputEvent::SyncEvent(SynchronizeFlags::empty())`，按 RDP 协议将全部普通键和修饰键恢复为松开，Caps／Num／Scroll／Kana 锁定均关闭；在最后已知鼠标位置发送左、中、右键抬起，与键盘重置一起入队，避免队列满时只执行一部分。仅明确请求时发送，不维护工具持键集合，也不在调用返回、取消、错误或对话结束时自动执行。

成功入队后清除 UI 本地键盘和鼠标按钮记录，并中止该连接尚未完成的定时工具序列，原调用返回 `RDP_INPUT_RESET`，避免旧序列随后再发送按下事件。入队失败不清除 UI 记录、不中止序列；不改变连接、页面租约或本地输入锁。回执含 `session_id`、`accepted`、`toggle_flags: 0` 和更新后的 `input_revision`，只证明入队，远端效果由截图检查。侧栏与窗口复用同一按钮处理逻辑，等待回执时禁用重复点击，失败可显式重试。

## 本地输入锁

连接默认未锁定。原生 Controls 维护 `ui_locked`，Node 后台只投影原生通知，页面合并原生回执和展示快照，按 UI 输入版本同步按钮与输入拦截，避免迟到状态覆盖较新的结果；工具 `control(ui_locked=true/false)` 与页面 `setUiLocked` 调用同一原生操作，明确设置布尔值且可重复调用。回执返回前已更新状态；派发后等待真实结果，取消不回滚锁。

切换锁时仅释放本地 UI 记录的键鼠；工具按键不登记在该集合。锁定和解锁分别递增独立的 UI 输入版本；WebSocket 键鼠及点击接管请求必须同时满足未锁定、当前输入版本和页面归属，迟到事件不在解锁后补发。输入版本与页面交接的 owner／epoch 分开，锁定不影响 claim 或移动。工具输入保持可用，锁不登记调用者、不排他于其他模型、不与对话关联。窗口移动和后台恢复保留同一连接的锁，新连接恢复未锁定；不增加持久化字段。

宿主标题栏用包内 `assets/lock.svg`／`assets/lock-open.svg` 及可选布尔 `pressed`，由共享选中按钮呈现；RDP 独立维护业务状态。最低宿主版本见本文开头。侧栏与标题栏都保留手动解锁、断开和关闭入口。

## 剪贴板

CLIPRDR 未完成协商时状态为 `initializing`；IronRDP 的 `on_ready` 通知通过原生快照和后台事件切换为 `disabled`。界面据此允许手动开启，桌面连接／首帧不代替剪贴板就绪。

配置 `clipboard_support` 是 v0 的可选布尔项，缺失为 false；TS 使用 `clipboardSupport`。连接时决定是否注册 CLIPRDR 静态通道；运行时共享状态不持久化，新连接为 false，页面交接及后台保留原状态。工具栏共用包内 `assets/clipboard.svg`，协议和系统剪贴板均留在插件原生进程。

`native/src/clipboard.rs` 复用 IronRDP 的格式协商、锁及文件请求；arboard 接入文本和本地文件列表。Windows 和 macOS 使用系统剪贴板变更序号检测变化，远端写入不再回传；开关代次隔离迟到响应。文件只公布相对路径和元数据，粘贴时读取，不经过模型 RPC。`clipboard/windows.rs` 用 OLE IDataObject、FileGroupDescriptorW 和 IStream 提供远端虚拟文件，按需分块拉取，未粘贴不读取内容；文件流和 `IDataObjectAsyncCapability` 保护整个粘贴操作，结束或取消会释放缓存流的占用；上行单独跟踪实际文件批次，不能把保留元数据的协议锁等同于传输中。单次读取等待失败只使该次粘贴失败，断开连接解除等待，不终止插件后台。

后台订阅宿主 `host.onViewsChanged`，结合 `getViews()` 初始快照选择活动连接。共享开关与同步活动状态独立；先撤销旧连接的新内容发布权，再授予当前连接，快速切换只应用最新状态。失焦立即停止新同步，原文件流继续，已发布文件仍可在本机粘贴；没有新连接接管时，失焦前已请求的文本允许完成，但本机剪贴板已变更时丢弃。新连接接管后原连接的迟到文本不能写入系统剪贴板。页面交接身份与活动状态分别管理，不用生命周期 `active` 推断焦点。

原生层区分共享、主动同步及发布权；暂停不清除文件清单、协议锁或在途读取。发布权代次隔离跨连接迟到响应，短锁保证旧发布完成后才确认撤销。状态为 disabled／syncing／paused／draining，经展示快照同步侧栏与标题栏提示。手动关闭共享在传输中仍返回 `RDP_CLIPBOARD_BUSY`。macOS 接入文本和本地文件上传，Finder 远端文件延迟粘贴未实现，不用预下载替代。

文本限制为 16 MiB，单次文件清单最多 10,000 条，遵循 FileGroupDescriptorW 的 259 个 UTF-16 单元相对路径限制，不跟随符号链接；内容分块读取，不设整个文件复制的总时长上限。上行取消由对端解锁或上游无活动回收解除占用，可能不会立刻允许关闭共享；活动连接切换仍可继续，旧传输单独收尾，不以终止后台解除限制。

2026-10-13 Intel macOS 探针验证：本轮 `NSFilePromiseProvider` 和旧 Pasteboard URL Promise 探针未能使 Finder 的普通粘贴可用；延迟 `public.file-url` 在粘贴前被读取。`NSFilePresenter` 可在协调读取时下载，但普通读取能拿到空占位文件；将占位文件设为不可读又使 Finder 禁用粘贴。这些方案均未进入产品，也不足以证明 macOS 无法按需粘贴。继续实现前须解决可靠的按需读取和失败语义，不以预下载或空文件占位替代。参考 [Apple 文件 Promise](https://developer.apple.com/documentation/appkit/nsfilepromiseprovider)。

### Finder 按需粘贴候选方案（尚未接入）

同日的 macOS 26.7.1 Intel 原型通过系统自带 `mount_webdav -S -o nobrowse,rdonly` 挂载插件本地的只读文件视图，将挂载路径写入剪贴板。挂载、查询目录和复制阶段只收到元数据请求；点击 Finder 粘贴后才收到内容 GET。3 MiB 二进制、中文文件名／emoji 文本、文件夹及空文件粘贴后逐字节一致。普通文件读取遇到 HTTP 500 返回错误，未成功读出空文件；终止 16 MiB 文件的读取进程后，少量在途请求结束，未继续下载完整文件。测试使用内存模拟内容，不涉及真实 RDP 文件；挂载点已卸载，剪贴板已恢复。探针及日志留在忽略的 `.local/clipboard-macos-probe/`。

尚未确定采用：远端内部复制也会触发本机挂载，触发时机仍不满足要求。原候选设计为由插件原生后台管理临时挂载和仅监听 loopback 的带随机访问凭据的只读服务，元数据来自当前 CLIPRDR 文件清单，GET／Range 复用现有分块读取与传输占用。每次复制使用独立代次路径，保留正在读取的清单，旧代次失效明确报错；不创建空占位文件、不新增下载入口、不向 Anas 宿主加入专用接口。剪贴板写入进程需持续存活，本轮对照发现过早退出会使多个剪贴板条目丢失。

进入产品前仍须验证真实 RDP 大文件和背压、Finder 取消按钮、复制替换／连接切换、缓存与挂载清理、异常退出及受支持旧版 macOS。当前仅验证普通读取进程的取消，不能代替 Finder 取消验收；系统按实际读取请求提供内容，预览或其他读取程序也可能触发下载，尚未证明所有场景都只在粘贴时读取。另一候选是 [File Provider](https://developer.apple.com/documentation/fileprovider/replicated-file-provider-extension)，它提供系统管理的按需文件及取消回调，但需独立 App Extension 的部署和生命周期，暂不优先采用。
