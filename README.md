# Anas RDP 插件

[English](README.en.md)

在 Anas 侧边栏或独立窗口使用 Windows 远程桌面。固定版本的 IronRDP 原生引擎在插件后台持有连接和画面，页面只负责 canvas 展示与键鼠输入，无需另行部署网关。

需要 **Anas 3.3.12 或更新版本**（插件 API 2），用于窗口适配、包内工具栏图标及后台页面活动订阅。请先升级宿主，再安装插件。

移动页面会重建展示界面，保留原连接和未保存输入；编辑页的「后台运行」默认关闭，关闭桌面即断开连接；勾选后关闭桌面保留连接，列表可「恢复桌面」或右键断开。右键可选择侧边栏或独立窗口启动／恢复；成功打开或移动后记住位置，后台桌面恢复也使用该位置。连接页与编辑页互斥；后台运行时禁止编辑和删除。点击「断开」、停止插件后台或退出宿主都会结束连接。

每台服务器可设置固定分辨率：1024×768、1280×800、1600×900、1920×1080、2560×1440 或自定义宽高，默认 1280×800。设置在下次建立连接时生效；调整窗口、移动页面及恢复后台桌面保持原分辨率。独立窗口首次按实际桌面尺寸自动调整；画面最多显示到 100%（一个远程像素对应一个界面逻辑像素），空间不足时等比缩小，空间充足时居中且不放大。标题栏「适配桌面大小」可再次调整窗口，必要时退出最大化／全屏；屏幕放不下时在当前工作区内缩小完整显示。侧边栏继续适配显示。

每台服务器的「支持剪贴板」默认关闭；开启后，连接工具栏和独立窗口标题栏才显示剪贴板开关。每次新连接默认不共享，各连接可以独立开启，移动页面或保留后台连接不改变开关。只有活动桌面同步新内容：独立窗口须在前台；侧边栏须选中且正在操作其标签、画面或工具栏，点击聊天区、收起或切走标签后暂停。鼠标悬停不激活。失活连接保留已复制内容的粘贴能力，已有文件传输继续收尾；新活动连接接管新的同步，不关闭其他连接的开关。手动关闭共享仍须等文件传输结束；关闭不撤回已经复制的文本。按钮提示显示同步中、待激活或传输收尾。

Windows 支持文件和文件夹双向复制粘贴，复制时仅交换目录信息，粘贴时按需读取内容，不预下载远端文件、不移动或删除源文件。macOS Intel 已实测文本双向复制、本地文件夹上传、多连接活动切换及传输取消／断开。取消上传后，占用可能需约一分钟才释放。远端文件直接粘贴到 Finder 尚未实现，已延期；Windows 多连接切换及本机 Explorer 粘贴／取消仍待补验。图片和富文本暂不支持。

## 使用

在 Anas「设置 → 插件」安装 ZIP，或选择完整目录中的 `PLUGIN.json`。从顶部插件菜单添加服务器、选择打开位置，双击条目或点击「启动」连接。编辑配置与连接页面分开，保存不启动连接，连接不隐式保存配置。安装、密码保护、证书和语言配置见随包[用户说明](docs/USER_GUIDE.md)。

最多保存 200 个服务器配置、同时保持 4 条连接。提供基本键鼠输入；本地输入法组合输入尚未支持，远端输入法及复杂快捷键的效果依赖目标应用。暂不提供声音或多显示器。

插件提供连接、服务器管理（增删改查）、键鼠控制、会话查询、后台截图、桌面展示和断开工具，在 Anas 能力设置中选用。截图直接返回 PNG 图片，桌面页面关闭后仍可读取存续连接的画面。连接使用已保存密码和既有证书信任；连接由插件独立管理，对话结束不改变连接或输入状态。`connect` 建立后台连接，`show_desktop` 显示桌面；“后台运行”决定关闭桌面后是否保留连接。键鼠输入支持 Unicode 文本 `text`、按键名、组合键及动作间隔；可在同一 `input.actions` 中先输入文本，再执行回车或 Ctrl+Enter，整批校验后忠实发送指定事件；底层 down/up 可跨调用使用，不记录或自动清理工具持键状态。文本按小批次节流，长输入超过 10 秒可转后台等待；单次输入到期只停止剩余步骤，不终止连接或插件后台。

「重置键盘」按钮与 `reset_keyboard(session_id)` 工具共用实现，发送 RDP Synchronize，锁定标志为 0：松开所有普通键和修饰键，同时关闭大小写、数字、滚动及 Kana 锁定。它只在明确调用时执行，不随工具返回或对话结束触发；会中止该连接尚未发完的工具输入序列（原调用返回 `RDP_INPUT_RESET`），不改变连接或本地输入锁。

侧边栏桌面工具栏和独立窗口标题栏提供「锁定本地输入」。选中后屏蔽本地键盘、鼠标和滚轮，画面与模型工具继续工作；解锁、断开和关闭入口始终可用。模型可通过 `set_ui_locked(session_id, locked)` 设置，`connect`、`list_sessions` 返回 `ui_locked`。锁属于当前连接，移动、后台恢复和对话结束均保留；新连接默认未锁定，不写入配置。模型完成连续操作后主动解锁，用户可随时手动解锁；它不限制其他工具调用者，手动解锁也不停止正在执行的工具。

Windows x64 已实测模型连接、查询、截图、断开、键鼠输入、页面交接、桌面展示和跨轮连接复用。macOS x64 已复核新增工具输入、本地输入锁、页面交接、后台恢复、跨轮连接复用、服务器列表定位和停止清理，并已核对 Unicode 工具输入的远端实际内容。详见[测试说明](docs/TESTING.md)。

## 开发

需要 Node.js 24 与 Rust 1.94.1。IronRDP 固定提交见 `upstream.lock.json`，依赖锁见 `native/Cargo.lock`。

```sh
npm ci
npm run typecheck
npm run build
npm test
npm run test:ui
```

`dist/` 为本平台可安装目录；日常不生成 ZIP。分发时运行 `npm run package` 和 `npm run verify:package`。CI 分别构建公共 UI、三平台原生程序并合并通用 ZIP，保留依赖许可证。
